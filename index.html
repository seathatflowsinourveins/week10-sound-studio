The versions matter.
Our examples use p5 2.3.4 + p5.sound 0.4.1. Original class sketches use several older versions; their API behavior can differ. The captured Mic Amp title says “v2” but its HTML loads 0.9.0. Each class resource has a version note.
New FFT values use 0–1, not the 0–255 range used in some older examples. A file load, audio activation, and microphone permission are three separate events.
